# Syrinx v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A self-hosted streaming speech-to-text server plus a headless Linux client that types transcribed speech at the cursor, replacing nerd-dictation + Vosk.

**Architecture:** A Rust workspace. `syrinx-proto` defines the wire protocol once so clients and server cannot drift. `syrinx-server` is an axum/tokio service exposing a WebSocket for streaming sessions and HTTP for bulk jobs, with ASR behind a trait so the whole protocol layer is testable without a GPU. `parakeet-type` is a small headless client that captures audio and types results via `wtype`. The server ships as a CUDA 12.8 container with models volume-mounted.

**Tech Stack:** Rust (edition 2024, MSRV 1.85), tokio, axum 0.8, tokio-tungstenite, serde/serde_json, cpal, parakeet-rs 0.3, ONNX Runtime 1.28 (CUDA 12 build).

**Spec:** `docs/specs/2026-08-20-syrinx-server-design.md`

---

## Scope

**In scope (v1):** `syrinx-proto`, `syrinx-server` (live + transcript modes, bulk jobs), `parakeet-type`, container packaging.

**Out of scope:** `syrinx-gui` (separate plan), session resume, TLS, diarization, multilingual, server-side transcript storage.

**Deliberately deferred:** performance benchmarking. Models sit behind the `AsrBackend` trait and can be swapped later without architectural change. Do not block on measurement.

```rust
use serde::{Deserialize, Serialize};

/// Which revision semantics a session uses.
///
/// `Live` is append-only because the client types into arbitrary applications,
/// where retracting characters is destructive if the user has typed or moved the
/// cursor since. `Transcript` clients own their buffer, so revision is safe.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum Mode {
    Live,
    Transcript,
}

impl Mode {
    /// Whether this mode may receive `provisional` / `revise` messages.
    pub fn allows_revision(self) -> bool {
        matches!(self, Mode::Transcript)
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum Encoding {
    PcmS16le,
    PcmF32le,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum ErrorCode {
    Unauthorized,
    Capacity,
    BadRequest,
    Internal,
}
```

```rust
use serde::{Deserialize, Serialize};
use crate::{Encoding, ErrorCode, Mode};

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(tag = "type")]
pub enum ClientMessage {
    #[serde(rename = "session.start")]
    SessionStart {
        mode: Mode,
        sample_rate: u32,
        encoding: Encoding,
        #[serde(default, skip_serializing_if = "Option::is_none")]
        language: Option<String>,
        #[serde(default, skip_serializing_if = "Option::is_none")]
        vocabulary: Option<Vec<String>>,
    },
    #[serde(rename = "session.flush")]
    SessionFlush,
    #[serde(rename = "session.stop")]
    SessionStop,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(tag = "type")]
pub enum ServerMessage {
    #[serde(rename = "session.ready")]
    SessionReady { session_id: String, chunk_ms: u32, model: String },

    /// Final text. Never revised. The only transcript message live mode emits.
    #[serde(rename = "transcript.commit")]
    TranscriptCommit { seq: u64, text: String },

    /// Text that may still change. Transcript mode only.
    #[serde(rename = "transcript.provisional")]
    TranscriptProvisional { seq: u64, text: String },

    /// Retract `retract_n` characters and replace with `text`.
    ///
    /// RESERVED. The streaming ASR is append-only (`transcribe_chunk` returns
    /// only newly emitted tokens), so no v1 code path emits this. It exists so a
    /// future post-processing layer can revise without a breaking protocol
    /// change. Its absence in v1 is intended, not a bug.
    #[serde(rename = "transcript.revise")]
    TranscriptRevise { seq: u64, retract_n: usize, text: String },

    #[serde(rename = "error")]
    Error { code: ErrorCode, message: String, retryable: bool },

    #[serde(rename = "session.closed")]
    SessionClosed { reason: String },
}
```

```rust
/// Target sample rate. The model is trained at 16 kHz; anything else must be
/// resampled by the client before sending.
pub const SAMPLE_RATE: u32 = 16_000;

/// Decode little-endian signed 16-bit PCM into normalised f32 samples.
/// A trailing odd byte is dropped rather than panicking, since network frames
/// can split mid-sample.
pub fn pcm_s16le_to_f32(bytes: &[u8]) -> Vec<f32> {
    bytes
        .chunks_exact(2)
        .map(|c| i16::from_le_bytes([c[0], c[1]]) as f32 / 32768.0)
        .collect()
}

/// Average interleaved channels down to mono.
pub fn downmix_to_mono(samples: &[f32], channels: u16) -> Vec<f32> {
    if channels <= 1 {
        return samples.to_vec();
    }
    let n = channels as usize;
    samples
        .chunks_exact(n)
        .map(|frame| frame.iter().sum::<f32>() / n as f32)
        .collect()
}
```

```rust
// crates/syrinx-server/src/asr/mod.rs
pub mod mock;

use anyhow::Result;

/// One independent decoding stream. Holds per-session decoder state.
pub trait AsrStream: Send {
    /// Feed one chunk of 16 kHz mono f32 audio, returning any newly emitted
    /// text. Returns an empty string when the model emitted nothing this chunk.
    ///
    /// Append-only by contract: implementations never retract previously
    /// returned text. See the spec on why revision cannot originate here.
    fn push(&mut self, audio: &[f32]) -> Result<String>;

    /// Flush trailing buffered audio at end of stream.
    fn finish(&mut self) -> Result<String>;
}

/// A loaded model able to spawn independent streams that share its weights.
pub trait AsrBackend: Send + Sync {
    fn stream(&self) -> Box<dyn AsrStream>;
    fn chunk_samples(&self) -> usize;
    fn model_name(&self) -> &str;
}
```

```rust
// crates/syrinx-server/src/session.rs
use crate::asr::{AsrBackend, AsrStream};
use anyhow::Result;
use syrinx_proto::{Mode, ServerMessage};

pub struct Session {
    mode: Mode,
    stream: Box<dyn AsrStream>,
    seq: u64,
    session_id: String,
    chunk_samples: usize,
    pending: Vec<f32>,
}

impl Session {
    pub fn new(mode: Mode, backend: &dyn AsrBackend, session_id: String) -> Self {
        Self {
            mode,
            stream: backend.stream(),
            seq: 0,
            session_id,
            chunk_samples: backend.chunk_samples(),
            pending: Vec::new(),
        }
    }

    pub fn session_id(&self) -> &str { &self.session_id }
    pub fn mode(&self) -> Mode { self.mode }

    /// Buffer audio and emit messages for every whole chunk now available.
    pub fn push_audio(&mut self, audio: &[f32]) -> Result<Vec<ServerMessage>> {
        self.pending.extend_from_slice(audio);
        let mut out = Vec::new();
        while self.pending.len() >= self.chunk_samples {
            let chunk: Vec<f32> = self.pending.drain(..self.chunk_samples).collect();
            let text = self.stream.push(&chunk)?;
            if !text.is_empty() {
                out.push(self.emit(text));
            }
        }
        Ok(out)
    }

    /// Zero-pad and flush any trailing partial chunk.
    pub fn finish(&mut self) -> Result<Vec<ServerMessage>> {
        let mut out = Vec::new();
        if !self.pending.is_empty() {
            let mut chunk: Vec<f32> = std::mem::take(&mut self.pending);
            chunk.resize(self.chunk_samples, 0.0);
            let text = self.stream.push(&chunk)?;
            if !text.is_empty() { out.push(self.emit(text)); }
        }
        let tail = self.stream.finish()?;
        if !tail.is_empty() { out.push(self.emit(tail)); }
        Ok(out)
    }

    /// All emission funnels through here.
    ///
    /// The ASR is append-only, so every message is a commit today. When a
    /// post-processing layer is added it emits provisional/revise from this
    /// point, and `Mode::allows_revision` is the gate that keeps live mode
    /// append-only. Routing all emission through one function is what makes
    /// that guarantee enforceable in one place.
    fn emit(&mut self, text: String) -> ServerMessage {
        self.seq += 1;
        ServerMessage::TranscriptCommit { seq: self.seq, text }
    }
}
```

```rust
// crates/syrinx-server/src/auth.rs
/// Constant-time-ish bearer comparison. The token is a LAN shared secret, not a
/// password hash, but avoid leaking length via early return where cheap.
pub fn check_bearer(header: Option<&str>, expected: &str) -> bool {
    if expected.is_empty() {
        return false;
    }
    let Some(h) = header else { return false };
    let Some(tok) = h.strip_prefix("Bearer ") else { return false };
    tok.as_bytes().len() == expected.as_bytes().len()
        && tok.as_bytes().iter().zip(expected.as_bytes()).fold(0u8, |a, (x, y)| a | (x ^ y)) == 0
}
```

```rust
/// Enforces that loading a model leaves at least `floor_mib` free for other
/// tenants on the GPU (Frigate, Jellyfin). Refusing is correct behaviour.
pub struct VramGuard { floor_mib: u64 }

impl VramGuard {
    pub fn new(floor_mib: u64) -> Self { Self { floor_mib } }

    pub fn can_load(&self, model_mib: u64, free_mib: u64) -> bool {
        free_mib > model_mib + self.floor_mib
    }
}
```

## Deferred

Benchmarking is deliberately deferred. Models sit behind `AsrBackend` and can be
swapped without architectural change. When measurement does happen, the numbers
that matter are: per-chunk inference time (sets `max_sessions`), model load time
(sets the keep-warm window), and CPU inference on Zen 1 (decides whether EOU
degradation is real or whether refusing is the only honest option).
